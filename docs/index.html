Installation & Setup Guide

🪟 Installing on Windows

  1. Choose amd64 for x86_64 PCs or arm64 for Windows ARM64, and download the matching installer above.
  2. Verify its SHA256 against SHA256SUMS.txt using PowerShell: 
    Get-FileHash .\vpro-windows-amd64-installer.exe -Algorithm SHA256
    Use the arm64 filename for that package. Only install a file from a release you trust; unsigned preview builds may trigger SmartScreen.
  3. Double-click the verified installer. The standalone executable and ZIP are alternatives to installation.
  4. Follow the on-screen installation wizard. VPRO will be installed to your Start Menu and Desktop.
  5. Launch VPRO from your desktop shortcut or Start Menu.

🍎 Installing on macOS

  1. Download the vpro-macos-universal.dmg file.
  2. Verify the download with shasum -a 256 vpro-macos-universal.dmg against SHA256SUMS.txt.
  3. Double-click the .dmg file to mount it, then drag vpro-wails.app into your Applications folder. The app archive is an alternative.
  4. If macOS Gatekeeper shows a warning that the app cannot be opened because it is from an unidentified developer:
    • First verify the checksum and trusted release source. Preview builds are ad-hoc signed, not Apple-notarized.
    • Right-click (or Control-click) on vpro-wails.app in your Applications folder and select Open.
    • In the dialog that appears, click Open to confirm. (You only need to do this once).

🐧 Running on Linux

  1. Check uname -m: use amd64 for x86_64 or arm64 for aarch64. Download the matching package and verify sha256sum against SHA256SUMS.txt.
  2. Open your terminal and grant execute permissions: 
    chmod +x vpro-linux-amd64.AppImage
  3. Execute the AppImage directly: 
    ./vpro-linux-amd64.AppImage
  4. Or for Debian/Ubuntu systems: 
    sudo apt install ./vpro-linux-amd64.deb
  5. Use the arm64 filename for aarch64. GTK4 and WebKitGTK 6.0 are required; AppImage does not remove this runtime requirement. If FUSE is unavailable, use --appimage-extract-and-run.
  6. For a tarball, run tar -xzf vpro-linux-amd64.tar.gz, install the required runtime libraries, then run ./vpro-wails.

About VPRO Wails

Modern ecosystem data processing without 32-bit legacy constraints.

VPRO is the standard software suite used across British Columbia and Western Canada for managing, validating, and analyzing vegetation survey plots, BEC (Biogeoclimatic Ecosystem Classification) codes, soil taxonomy, site descriptions, and species inventory.

This next-generation cross-platform release replaces legacy 32-bit Microsoft Access runtime dependencies with a high-performance Go and Wails v3 architecture, canonical SQLite project storage, and responsive modern Svelte user interfaces.
